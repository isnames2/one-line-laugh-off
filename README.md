One funny line for the make.fun competition "One-Line Laugh-Off": a single
joke that lands on a cold read, with no setup notes and no explanation.

Competition page: https://make.fun/bounty/u-zkhiel-one-line-laugh-off-714618ae

## The line

> My fitness tracker congratulated me on 10,000 steps. 9,000 of them were to the fridge.

## Run

```sh
python3 main.py   # writes entry.txt to $MAKEFUN_OUTPUT_DIR (default /output)
```

Pure Python standard library; the output is byte-identical on every run.
